# ESKA Contacts & Renewals Report
> اداة لسحب بيانات التواصل من بوابة إسكا وتوليد تقارير التجديدات

تتكون الأداة من سكريبتين:
- **`eska_contacts.py`** — يقرأ ملف الذمم XLS، يسجّل الدخول إلى بوابة إسكا عبر Playwright، ويسحب بيانات التواصل (هاتف، جوال، بريد) لكل وثيقة.
- **`renewals_report.py`** — يدمج بيانات الذمم مع بيانات التواصل ويُنشئ تقرير إكسل مُنسَّقًا يُمييز الوثائق العاجلة بالألوان.

---

## متطلبات التشغيل

### ١. تثبيت المكتبات

```bash
pip install playwright pandas openpyxl xlrd
playwright install chromium
```

### ٢. ضبط متغيرات البيئة

```bash
# Linux / macOS
export ESKA_PASS=كلمة_المرور
export ESKA_USER=اسم_المستخدم     # اختياري، إذا تطلّبته البوابة

# Windows
set ESKA_PASS=كلمة_المرور
set ESKA_USER=اسم_المستخدم
```

## الاستخدام

### سحب بيانات التواصل

```bash
# سحب كامل — جميع الوثائق (مثلاً ٥٦٣)
python eska_contacts.py "ذمم.xls"

# التجديدات فقط — الوثائق المنتهية خلال ٩٠ يومًا (مثلاً ٣٤٨)
python eska_contacts.py "ذمم.xls" --renewals-only

# تحديد اسم ملف الإخراج
python eska_contacts.py "ذمم.xls" --out my_contacts.xlsx

# تشغيل المتصفح بواجهة مرئية للتشخيص
python eska_contacts.py "ذمم.xls" --no-headless
```

المخرجات: `contacts.xlsx` (أو الاسم الذي حددته بـ `--out`).

### توليد تقرير التجديدات

```bash
python renewals_report.py "ذمم.xls" --contacts contacts.xlsx

# تحديد اسم ملف التقرير
python renewals_report.py "ذمم.xls" --contacts contacts.xlsx --out تقرير.xlsx
```

المخرجات: `تقرير_التجديدات.xlsx` يحتوي على ثلاث أوراق:

| الورقة | المحتوى |
|--------|---------|
| **التجديدات** | الوثائق المنتهية خلال نافذة التجديد مع تلوين حسب الإلحاح |
| **الكل** | جميع الوثائق مع بيانات التواصل |
| **ملخص** | إحصائيات: عدد التجديدات، توزيع الإلحاح، معدل توافر التواصل |

#### مفتاح الألوان في التقرير

| اللون | المعنى |
|-------|--------|
| 🔴 أحمر فاتح | تنتهي خلال 0–30 يومًا |
| 🟡 أصفر فاتح | تنتهي خلال 31–60 يومًا |
| ⬜ عادي | تنتهي خلال 61–90 يومًا |

## الإعداد والتخصيص

افتح `eska_contacts.py` وعدّل الثوابت في أعلى الملف:

| الثابت | الوصف |
|--------|-------|
| `ESKA_BASE_URL` | رابط بوابة إسكا الأساسي |
| `ESKA_LOGIN_PATH` | مسار صفحة تسجيل الدخول |
| `ESKA_SEARCH_PATH` | مسار صفحة البحث عن الوثائق |
| `SEL_*` | محددات CSS لعناصر HTML في البوابة |
| `COL_*` | أسماء أعمدة ملف الذمم |
| `RENEWAL_DAYS` | نافذة التجديد بالأيام (افتراضي: 90) |

## المعاملات

### `eska_contacts.py`

| المعامل | الوصف |
|---------|-------|
| `xls` | مسار ملف الذمم (إلزامي) |
| `--renewals-only` | سحب التجديدات فقط |
| `--out` | مسار ملف الإخراج (افتراضي: `contacts.xlsx`) |
| `--url` | رابط بوابة إسكا (يتجاوز `ESKA_URL`) |
| `--no-headless` | تشغيل المتصفح بواجهة مرئية |

### `renewals_report.py`

| المعامل | الوصف |
|---------|-------|
| `xls` | مسار ملف الذمم (إلزامي) |
| `--contacts` | مسار ملف التواصل (إلزامي) |
| `--out` | مسار ملف التقرير (افتراضي: `تقرير_التجديدات.xlsx`) |
